# Лабораторна робота №1

Цей репозиторій створено в рамках виконання лабораторної роботи №1

## Проєкт: Backend-сервіс управління подіями
В якості тестового проєкту сюди було завантажено мою курсову роботу - REST API сервіс для управління різноманітними подіями.

### Призначення проєкту:
Система забезпечує зберігання та обробку інформації про події, організаторів і учасників. Користувачі можуть створювати події, редагувати їхню інформацію, а учасники — реєструватися на них.

### Основна функціональність (REST API):
* **Управління сутностями (CRUD):** Робота з подіями (`Event`), організаторів (`Organizer`), учасниками (`Participant`), категоріями (`Category`) та реєстраціями (`Registration`).
* **Система реєстрацій:** Реєстрація учасників на події, перевірка та оновлення статусу реєстрації.
* **Повнотекстовий та розширений пошук:** Пошук подій за назвою, описом, датою та локацією.
* **Аналітика:** Отримання загальної статистики (кількість подій, учасників, майбутніх/минулих подій).
* **Моніторинг:** Відстеження стану сервісу через `/actuator/health` та збір метрик для Prometheus.
